# Blue LED tracking

## Capture training frames

Run `python capture_dataset.py` with the blue LED visible to the webcam.
Press **R** to start recording and press **R** again to stop. Only frames
containing a bright-blue region are saved; OpenCV creates YOLO box labels
from those regions and puts 20% of each recording session into validation.
Press **Esc** to quit. Capture the LED at different positions, distances, and
lighting conditions for a more robust model.

The automatic labels use an HSV color threshold (`LOWER_BLUE` and `UPPER_BLUE`
in `capture_dataset.py`) and can include blue clothing, reflections, or other
blue regions.

## Review labels

Run `python review_dataset.py` before training. Drag a tight box around each
LED; boxes are drawn in green. Use **U** to undo the last box, **C** to clear
the current frame, **Enter** to save the boxes and continue, **N** to mark a
frame as containing no LED, or **Q** to quit and resume later. The first time
you edit a frame, its generated label is backed up under
`blue_led_dataset/labels_autogenerated/`. Reviewed progress is recorded in
`review_manifest.json`.

## Train and track

Install dependencies with `pip install -r requirements.txt`. For NVIDIA GPU
training, install the CUDA 12.8 PyTorch wheel in the same environment:

```powershell
python -m pip install --force-reinstall torch==2.11.0+cu128 torchvision==0.26.0+cu128 --index-url https://download.pytorch.org/whl/cu128
```

Capture frames and manually review all images before training. The training
script checks that CUDA is available and uses GPU 0, automatic batch sizing,
and mixed precision. Run `python train_model.py`; the best weights are saved
to `runs/detect/blue_led/weights/best.pt`. Run the tracker with
`python main.py`.

## Shape tracing game

Run `python shape_tracing_game.py` to play with the trained blue LED model.
The webcam preview is mirrored. Trace a square, triangle, and circle using the
LED; press **Space** to start each 20-second round. Each grade is based on
average distance from the target outline and how much of that outline you
traced within the allowed tolerance. Grades are A (90+), B (80+), C (70+),
D (60+), and F (below 60). Press **R** on the results screen to play again,
or **Esc** to exit.
